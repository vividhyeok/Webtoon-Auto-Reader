# Webtoon Auto Reader 2.0

네이버 웹툰의 원래 화면을 유지하면서 **스크롤 → 정지 → 읽기**를 반복하는 Manifest V3 Chrome 확장 프로그램입니다. 외부 서버, 유료 API, 런타임 라이브러리 없이 동작하며 설정과 장면은 이 기기에만 저장됩니다.

## 바로 사용하기

1. 네이버 웹툰의 개별 회차를 엽니다.
2. 확장 프로그램 아이콘을 누르고 **재생**을 선택합니다. 신규 설치는 읽기형이 기본입니다.
3. 식사할 때는 **식사**, 보조 모니터에서 게임과 함께 볼 때는 **게임 병행**, 집중해서 볼 때는 **집중 감상** 프리셋을 선택하세요.
4. 놓친 장면은 **이전 1회 / 3회**로 돌아간 뒤 재생합니다. 돌아간 직후에는 일시정지합니다.

브라우저가 포커스를 잃어도 표시 중인 웹툰은 계속 재생합니다. 다른 탭으로 전환하여 문서가 숨겨지면 프레임과 대기시간을 멈추며, 다시 표시할 때 밀린 거리를 한꺼번에 이동하지 않습니다. 팝업을 닫아도 재생합니다.

## 세 가지 스크롤 모드

| 모드          | 동작                                   | 기본 설정                                                      |
| ------------- | -------------------------------------- | -------------------------------------------------------------- |
| 읽기형 (추천) | 일정 거리 이동 → 화면 고정 → 다음 이동 | 화면 25%, 280ms 감속, 2.5초 읽기                               |
| 혼합형        | 짧게 이동하고 짧게 쉬는 리듬           | 모드 선택 시 템포에 맞춰 계산; 집중 프리셋은 15%, 220ms, 0.8초 |
| 연속형        | 일정한 px/s 속도로 부드럽게 이동       | 10~2,400px/s, 기존 설정 유지                                   |

이동 거리 100%는 화면 한 개, 300%는 화면 세 개 높이입니다. 템포의 빠른 끝에서 읽기형은 300%, 혼합형은 150%, 연속형은 2,400px/s까지 선택할 수 있습니다.

감상 템포를 빠르게 할수록 읽기 대기가 짧아지고 이동 거리·애니메이션 시간 또는 연속 속도가 함께 바뀝니다. 프리셋 적용 후 세부값을 바꾸면 **사용자 지정**으로 표시합니다. 게임 병행은 화면 20%, 5초 읽기, 마지막 컷 6초이며 식사는 25%, 3.5초 읽기입니다.

## 고급 설정

팝업의 **고급 설정**을 펼치세요. 변경 즉시 열린 웹툰에 반영되며 Chrome local storage에 보관됩니다.

| 항목                   | 범위와 역할                                              |
| ---------------------- | -------------------------------------------------------- |
| 연속형 속도            | 10~2,400px/s. 연속형에서 사용                            |
| 이동 거리              | 화면 높이의 10~300%. 읽기형·혼합형에서 사용              |
| 이동 애니메이션        | 100~800ms. 이동하는 데 걸리는 시간                       |
| 읽기 대기              | 0.5~6초. 이동 후 화면을 고정하는 시간                    |
| 감속 곡선              | 부드러운 cubic 감속 또는 일정한 이동                     |
| 수동 조작 시 일시정지  | 휠·터치·스크롤 키·스크롤바 조작에 제어권 양보. 기본 켜짐 |
| 수동 조작 후 자동 재개 | 기본 꺼짐. 켜면 마지막 조작 후 재개                      |
| 재개 대기              | 1~30초. 반복 입력 시 다시 기다림                         |
| 마지막 컷 감상         | 0.5~15초. 본문이 충분히 보인 뒤 확보하는 시간            |
| 다음 회차 대기         | 0~10초. 마지막 컷 감상 후 추가로 기다리는 시간           |

**기본값 초기화**는 설정만 초기화하며 장면 수집함은 유지합니다. 1.x에서 저장한 속도는 연속형으로 마이그레이션합니다. 탭별 재생 세션은 분리되며 브라우저 종료 뒤에는 자동 재생하지 않습니다.

## 장면 수집함

- **장면 저장** 또는 Alt+B: 작품·회차·URL·저장일시·이미지 번호와 상대 위치를 저장합니다.
- **저장 + 화면 캡처**: 재생을 멈추고 위치를 먼저 저장한 다음 현재 탭의 **보이는 화면 전체**를 PNG로 캡처합니다. 화면에 포함된 사이트 UI도 함께 찍힙니다. 캡처 실패·권한 거부 시 위치 북마크는 유지합니다.
- **장면 수집함 열기**: 이미지 카드에서 작품별 필터, 작품·태그·메모 검색, 태그와 메모 편집, 삭제를 사용할 수 있습니다.
- **이 위치에서 열기**: 새 탭에서 해당 회차로 이동하여 이미지 로딩을 기다린 뒤 위치를 복원합니다. 재생은 일시정지 상태입니다.
- 캡처 이미지는 확장 프로그램의 IndexedDB에 저장됩니다. 카드에서 파일로 저장하거나 **이미지만 삭제**, **장면 삭제**를 선택할 수 있습니다.
- 북마크는 최대 1,000개, 되돌리기 기록은 탭 메모리에 최대 200개입니다. 연속형은 1.5초 간격으로 위치를 샘플링합니다.

캡처는 명시적인 버튼 클릭 때만 수행합니다. 전체 회차를 일괄 다운로드하거나 로그인·유료·잠금 보호를 우회하지 않습니다. 확장 프로그램을 제거하면 로컬 설정과 수집함도 삭제될 수 있습니다.

## 다음 무료 회차와 오류 처리

본문 마지막 이미지가 화면 안에 들어온 뒤 마지막 컷 감상시간과 다음 회차 대기시간을 각각 적용합니다. 이때 스크롤은 멈추며 댓글·추천 영역으로 진행하지 않습니다.

페이지가 제공하는 `nextArticle`의 명시적 무료·비잠금 상태 또는 무료 표시가 있는 같은 작품의 다음 회차 링크만 사용합니다. 유료·잠금·무료 여부 불명확·다른 작품 링크는 자동 이동을 중단합니다. URL과 작품·회차를 검증한 의도된 다음 이동만 자동 재개합니다.

보이는 이미지가 로딩 중이면 최대 12초 기다립니다. 실패 이미지는 경고 후 진행하고 본문이 없으면 20초 뒤 멈춥니다. 사이트 구조 변경이나 실제 스크롤 불가능 상태에서는 안전하게 중단합니다.

## 단축키

| 동작             | 웹툰 페이지 | Chrome 확장 명령 |
| ---------------- | ----------- | ---------------- |
| 재생 / 일시정지  | Alt+P       | Alt+Shift+P      |
| 위치 북마크 저장 | Alt+B       | Alt+Shift+B      |
| 이전 위치 복귀   | Alt+Z       | Alt+Shift+Z      |

`chrome://extensions/shortcuts`에서 확장 명령을 변경할 수 있습니다. 입력 필드에서는 페이지 단축키를 무시합니다. OS·브라우저·게임의 단축키 점유에 따라 동작하지 않을 수 있으므로 팝업 버튼도 사용할 수 있습니다. 기본 확장 명령은 전역 단축키로 설정하지 않습니다.

## Chrome 설치와 업데이트

1. 저장소를 복제하거나 **Code → Download ZIP**으로 받아 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. **개발자 모드**를 켭니다.
4. **압축 해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `manifest.json`이 직접 들어 있는 **폴더**를 선택합니다. ZIP 또는 manifest 파일 자체를 선택하지 않습니다.
6. 네이버 웹툰 회차를 새로고침하고 확장 프로그램을 실행합니다.

업데이트는 같은 폴더에서 `git pull`하거나 새 파일로 교체한 뒤 확장 관리 화면의 **새로고침** 버튼을 누르고, 열려 있는 웹툰도 새로고침합니다. 별도 빌드 없이 저장소 루트 폴더를 바로 불러올 수 있습니다.

## 개발 · 검증 · ZIP

Node.js 24 이상을 사용합니다. `npm install`이 필요하지 않습니다.

```sh
npm test
npm run check
npm run test:browser
npm run pack
```

- `test`: 기존 엔진·어댑터 테스트와 설정 마이그레이션, 리듬·시간·경계·되돌리기·독립 세션·장면 저장 테스트.
- `check`: 모든 JS 문법 및 manifest 참조 파일 존재 검사.
- `test:browser`: 실제 headless Chrome과 로컬 DOM fixture로 엔진·content controller·이미지 실패·본문 제거·북마크 복귀·IndexedDB를 검증합니다. Chrome API는 fixture에서 대역을 사용하며 실제 네이버 서비스 접속 검증은 아닙니다. Windows 기본 Chrome 경로를 사용하고 다른 경로는 `CHROME_PATH` 환경변수로 지정합니다.
- `pack`: Windows PowerShell의 Compress-Archive로 `dist/webtoon-auto-reader-2.0.1.zip`을 생성합니다. 런타임 파일과 README만 포함하며 개발 파일·테스트·Git 이력은 제외합니다.
- GitHub Actions는 Windows에서 테스트·정적 검사·브라우저 fixture·ZIP 생성을 실행하고 ZIP을 artifact로 보관합니다.

## 권한과 알려진 제약

- `storage`: 설정·장면 메타데이터·탭별 세션. `activeTab`: 사용자가 확장 아이콘을 누른 활성 탭의 화면 캡처. 네이버 웹툰 호스트 권한만 요청하며 광범위한 `tabs` 권한은 제거했습니다. [Chrome Tabs API 문서](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)
- 네이버 웹툰 상세 회차만 지원합니다. 사이트 DOM·상태 스크립트 변경 시 어댑터 수정이 필요할 수 있습니다.
- Chrome이 창을 완전히 가리거나 최소화하면 보조 모니터에서도 브라우저 자체가 렌더링을 제한할 수 있습니다. 브라우저 포커스 상실과 문서 숨김은 구분합니다.
- 이미지 구성·크기·콘텐츠가 변경되면 북마크 상대 위치가 달라질 수 있습니다. 이미지 번호를 찾지 못하면 저장된 스크롤 위치를 사용합니다.
- 무료 여부를 보수적으로 판단하므로 실제 무료 회차라도 명시적 증거가 없으면 멈춥니다.
- 화면 캡처의 실제 권한 승인, 로그인 세션, 다중 모니터와 게임 조합은 사용자 환경에서 추가 확인이 필요합니다.
- PIP·네이티브 오버레이·웹 스토어 배포는 포함하지 않습니다.
