# Webtoon Auto Reader

네이버 웹툰 회차를 일정한 속도로 부드럽게 자동 스크롤하고, 본문의 마지막 이미지까지 읽으면 다음 **무료 회차**로 이어서 이동하는 Chrome 확장 프로그램입니다.

## 주요 기능

- 10~600 px/s 범위의 실제 이동 거리 기반 속도 설정
- 재생, 일시정지, 재개, 완전 중지
- 팝업을 닫아도 계속되는 `requestAnimationFrame` 자동 스크롤
- 마지막 본문 이미지를 기준으로 한 회차 종료 감지
- 0~10초 대기 후 다음 무료 회차 자동 이동
- 다음 회차에서도 속도와 재생 상태 복원
- 탭별 독립 세션 및 새로고침 복원
- 백그라운드 탭 자동 일시정지 및 복귀 시 안전한 재개
- 라이트/다크 모드를 따르는 미니멀 팝업

개인정보, 감상 기록을 외부로 전송하지 않으며 웹툰 이미지를 저장하지 않습니다.

## 지원 플랫폼

- 네이버 웹툰: `https://comic.naver.com/webtoon/detail?...`
- Chrome Manifest V3 호환 브라우저

다른 웹툰 플랫폼은 아직 지원하지 않습니다. 사이트별 로직은 `content/adapters/`에 분리되어 있습니다.

## Chrome 설치 방법

1. 이 GitHub 저장소의 **Code → Download ZIP**을 선택합니다.
2. ZIP 파일의 압축을 풉니다.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위의 **개발자 모드**를 켭니다.
5. **압축 해제된 확장 프로그램을 로드합니다**를 클릭합니다.
6. 압축을 푼 폴더 중 `manifest.json`이 바로 들어 있는 `Webtoon-Auto-Reader` 폴더를 선택합니다.
7. 네이버 웹툰의 개별 회차 페이지에서 확장 프로그램 아이콘을 누릅니다.

## 사용 방법

1. 네이버 웹툰 회차 페이지를 엽니다.
2. 확장 프로그램 팝업에서 속도를 선택합니다. 기본값은 `80 px/s`입니다.
3. **재생**을 누릅니다.
4. 필요할 때 **일시정지** 또는 **중지**를 누릅니다.

속도 슬라이더는 재생 중에도 즉시 반영됩니다. **다음 회차 자동 이동**을 켜고 대기시간을 선택하면 본문 마지막 이미지가 충분히 보인 뒤 설정한 시간만큼 기다렸다가 다음 무료 회차로 이동합니다. 일시정지하면 대기 카운트다운도 멈춥니다.

## 프로젝트 구조

```text
├── manifest.json
├── background/service-worker.js  # 탭별 세션 보존 및 메시지 중계
├── content/
│   ├── content.js                 # 페이지 재생 상태와 연속 감상
│   ├── scroll-engine.js           # 시간 기반 스크롤 엔진
│   └── adapters/naver.js          # 네이버 DOM 및 다음 회차 탐색
├── popup/                         # 확장 프로그램 UI
└── tests/                         # Node 내장 테스트
```

## 개발 및 테스트

별도의 설치나 빌드는 필요하지 않습니다. Node.js가 있으면 아래 검사를 실행할 수 있습니다.

```bash
npm test
npm run check
```

## 알려진 제한사항

- 네이버가 페이지 DOM이나 URL 구조를 변경하면 어댑터 갱신이 필요할 수 있습니다.
- 유료·잠금 여부를 확실히 판단할 수 없으면 안전을 위해 자동 이동을 중단합니다.
- 접근 제한, 로그인 요구, 네트워크 오류를 우회하지 않습니다.
- 브라우저를 완전히 종료한 뒤에는 이전 재생 세션을 자동 재개하지 않습니다. 속도 등 사용자 설정만 유지됩니다.
- Chrome 웹 스토어에는 게시하지 않았으며 개발자 모드 설치가 필요합니다.
